项目概览

这是一个基于点云处理的扫描检测系统，主要用于火车、汽车和AGV等运输工具上的货物（如钢卷、鞍座）的识别。项目采用PCL（Point Cloud Library）进行点云处理，实现了模式匹配、点云分割、几何拟合等功能。

系统架构

  • 基础层: types.h/types.cpp 提供基础数据结构定义
  • 算法层: extensions.h/extensions.cpp 提供点云处理算法
  • 配置层: config.h/config.cpp 提供系统配置管理
  • 核心层: scan.h/scan.cpp 提供扫描系统的基类和主检测流程
  • 业务层: train_scan.h/cpp、car_scan.h/cpp、agv_scan.h/cpp 针对不同场景的扫描实现
  • 接口层: scan_export.h/scan_export.cpp 提供DLL导出接口

关键算法流程

  1. 预处理: 点云缩放、坐标系转换、点云裁剪
  2. 车厢检测: 通过聚类和尺寸筛选识别车厢
  3. 车厢分割: 将车厢分割为鞍座和钢卷区域
  4. 平面拟合: 拟合车厢底面平面
  5. 特征识别: 分别识别钢卷和鞍座
  6. 结果验证: 对检测结果进行验证和过滤
