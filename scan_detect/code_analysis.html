扫描检测系统代码分析文档

1. 项目概述

本项目是一个基于PCL（Point Cloud Library）的3D点云扫描检测系统，主要用于识别货车车厢中的钢卷和鞍座位置。

  • 技术栈：C++17, PCL, Boost, CMake
  • 主要功能：从3D点云数据中识别车厢类型，并检测车厢内的钢卷和鞍座
  • 支持类型：平板货车、高栏式货车、火车车厢、AGV

4. 关键算法

4.1 点云预处理

  • 自动缩放：根据期望尺寸判断点云单位（m/mm），自动转换
  • 坐标转换：检测车厢轴向，必要时交换XY坐标，确保X为长度方向
  • 裁剪：自动或手动裁剪，去除地面、扫描头上方干扰点
  • 降噪：SOR（Statistical Outlier Removal）滤波去除离群点

4.2 车厢识别

  • 聚类：欧几里得聚类，根据车厢长宽高筛选
  • 类型判断：
    • 提取头部和尾部区域点云（各10%）
    • 计算区域高度
    • 如果头尾高度都大于阈值（750mm），判定为高栏车厢
  • 边界计算：拟合车厢底部平面，计算四个顶点

4.3 钢卷识别

  • 聚类分离：欧几里得聚类分离单个钢卷
  • 尺寸验证：检查X、Y、Z方向尺寸是否符合钢卷特征
  • 点云降噪：SOR滤波，裁剪侧面和轴向异常点
  • 圆柱拟合：使用robustFitCylinder算法拟合圆柱体，计算直径和角度

4.4 鞍座识别

  • 平板车厢：
    • 提取鞍座突出点（基于平面距离）
    • 聚类提取特征点
    • 模式匹配：与预定义的Chassis特征点进行匹配
    • 计算鞍座中心位置
  • 高栏车厢：
    • 去除围栏：内缩边界裁剪
    • 提取底部点云，去除平面点云
    • 聚类分离单个鞍座
    • PCA分析计算矩形相似度
    • 根据长度、长宽比、高度、相似度判断
    • 合并断裂的鞍座

4.5 结果合并与过滤

  • 冲突处理：根据钢卷结果剔除重叠的鞍座
  • 边界过滤：确保钢卷和鞍座在车厢范围内
  • 参数过滤：根据最大宽度、直径等参数过滤异常结果
  • 结果验证：检查车厢间隔、库位间隔是否合理

5. 主要模块说明

5.1 Scan类（核心基类）

主要方法：
  • detect(): 主检测流程，协调各个步骤
  • cleanPointCloud(): 点云预处理和裁剪
  • getCarriages(): 提取车厢信息（纯虚函数，由子类实现）
  • detectCoils(): 识别钢卷
  • detectSaddles(): 识别鞍座
  • mergeDetectResult(): 合并和过滤检测结果

5.2 CarScan类（汽车扫描）

特点：
  • 继承自Scan，实现汽车特定的车厢提取逻辑
  • 支持平板和高栏两种车厢类型
  • 实现特殊的鞍座识别（支持草垫识别）

5.3 TrainScan类（火车扫描）

特点：
  • 继承自Scan，实现火车车厢提取逻辑
  • 预定义了多种火车底盘模式（TRAIN_CHASSIS）
  • 通过顶部边框识别车厢

5.4 AgvScan类（AGV扫描）

特点：
  • 继承自CarScan
  • 预定义了AGV底盘模式（AGV_CHASSIS）
  • 支持多种鞍座配置（1个、2个、3个鞍座）

5.5 工具模块

模块 功能
extensions 点云处理扩展函数（裁剪、滤波、聚类等）
pattern 模式匹配算法，用于鞍座特征点匹配
config 配置管理，支持JSON格式的配置文件
scan_export 结果导出功能

6. 配置参数说明

参数类别 关键参数 说明
车厢尺寸 car_length, car_width, car_height 车厢的长宽高，用于筛选车厢聚类
裁剪范围 cloud_crop_x/y/z_min/max 点云裁剪范围，去除干扰区域
钢卷参数 coil_max_width, coil_max_diameter 钢卷最大宽度和直径，用于验证
鞍座参数 saddle_length_min, saddle_length_width_ratio_min/max 鞍座尺寸阈值，用于高栏车厢鞍座识别
聚类参数 cluster_tolerance, cluster_min_size 欧几里得聚类的容差和最小点数
SOR参数 sor_mean_k, sor_stddev_mul_thresh 统计离群点去除的参数

8. 关键设计模式

  • 模板方法模式：Scan类定义检测流程框架，子类实现特定步骤
  • 策略模式：不同车辆类型（Car/Train/AGV）使用不同的识别策略
  • 配置模式：通过ScanConfig集中管理所有参数

10. 总结

本系统是一个完整的3D点云处理和分析系统，主要特点：

  • 模块化设计：通过继承实现不同车辆类型的支持
  • 可配置：通过JSON配置文件灵活调整参数
  • 鲁棒性：包含多层过滤和验证机制
  • 可扩展：易于添加新的车辆类型和识别算法

系统通过点云聚类、平面拟合、圆柱拟合、模式匹配等多种算法，实现了对车厢、钢卷、鞍座的准确识别。
